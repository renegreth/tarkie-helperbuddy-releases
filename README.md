# Tarkie Helperbuddy

A companion for Escape from Tarkov (PvE): prices, top flips, trends, your flea sales, quests with wiki guides,
needed items and keys, interactive maps, ammo, the hideout, an in-game price box on a shortcut, and your friends'
quests beside your own.

**[Download the latest version](https://github.com/renegreth/tarkie-helperbuddy-releases/releases/latest/download/ElapsTarkiebuddy.exe)**
· [tarkie-helperbuddy.vercel.app](https://tarkie-helperbuddy.vercel.app)

- Windows 10 or 11. Nothing to install: save the file and run it.
- You need an account and a product code to sign in. [Request a code](https://tarkie-helperbuddy.vercel.app/#request)
  and you'll get it by mail once it's approved.
- Windows may warn that the file is unknown, because it isn't signed with a paid certificate.
  Press "More info" and then "Run anyway".

This repository holds the releases only. The program reads prices and quest data from
[tarkov.dev](https://tarkov.dev) and reads Tarkov's own log files; it never touches the game itself.
